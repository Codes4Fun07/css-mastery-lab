# CSS Mastery Lab 🎨

A collection of hands-on CSS examples to learn and practise CSS properties, from fundamentals to advanced concepts.

## Topics Covered

- **Fundamentals** — Basic CSS properties
- **Display** — Block, inline, and inline-block
- **Positioning** — Static, relative, absolute, fixed, and sticky
- **Typography** — Fonts and text styling
- **Z-Index** — Stacking order of elements

## Technologies Used

- HTML5
- CSS3
